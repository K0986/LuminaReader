# LuminaReader

A modern book reader Android app built with Kotlin.

## Features

- 📚 Browse and read books
- 🎨 Customizable reading experience
- 📖 Bookmark your favorite passages
- 🌙 Dark mode support
- 💾 Offline reading capability

## Tech Stack

- **Language**: Kotlin
- **Platform**: Android
- **Architecture**: Modern Android development practices

## Getting Started

### Prerequisites

- Android Studio (latest version)
- Android SDK 21 or higher
- Kotlin plugin for Android Studio

### Installation

1. Clone the repository:
```bash
git clone https://github.com/K0986/LuminaReader.git
cd LuminaReader
```

2. Open the project in Android Studio

3. Build and run on your device or emulator:
```bash
./gradlew build
./gradlew installDebug
```
